## Projects

### [Sila](https://alinasser.info) &nbsp;<img alt="" src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white"/>&nbsp;<img alt="" src="https://img.shields.io/badge/GTK4-4A86CF?style=flat-square&logo=gtk&logoColor=white"/>

*صلة — Arabic for a bond, a tie, a connection between people.*

A personal operating system whose interface assembles itself around each user.
The shell renders its UI from declarative specs, remembers exactly what you left
open across reboots and updates, and targets the Raspberry Pi 5.

### [Journal for macOS](https://github.com/itssali/Journal-for-macOS) &nbsp;<img alt="GitHub stars" src="https://img.shields.io/github/stars/itssali/Journal-for-macOS?style=flat-square&color=6366F1&labelColor=475569"/>

A native journaling app for macOS, built because Apple never brought theirs over
from iOS. SwiftUI throughout, with emotion tracking, writing statistics, and
entries organized by month.
