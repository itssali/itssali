A native journaling app for macOS, built because Apple never brought theirs over from
iOS. SwiftUI throughout, with emotion tracking, writing statistics, and entries organized
by month.

An open-source e-commerce platform in a Turborepo monorepo — Next.js storefront, admin

Google queries straight from the shell, plus weather and system info.
